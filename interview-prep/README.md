# Interview Prep

This directory is my active data-structures-and-algorithms interview-prep workspace.

The goal is not to collect as many solved problems as possible. It is to rebuild the core patterns well enough to:

- recognise the right approach from problem constraints;
- explain why the approach works;
- reason about time and space complexity;
- implement it cleanly without relying on memorised code;
- identify common failure modes and edge cases.

## How I am studying

For each pattern:

1. Learn the underlying invariant or decision rule.
2. Derive the algorithm rather than memorising it.
3. Dry-run it manually.
4. Solve representative problems.
5. Record mistakes and edge cases.
6. Revisit the pattern through spaced repetition.
